Design system

Hand-written specimens, not a hosted tool. Every value lives in tokens.css as a custom property, every specimen links that one file, and scripts/validate-design-tokens.cjs keeps the two honest.

Screens

Settled, and none drawn. A screen is a surface a user reaches by route, so there are two of them and one task each: 16-design-the-library, at / on web and the root on mobile, and 17-design-the-playlist-detail, at /playlists/:id on web and pushed over the root on mobile. Each record carries both arrangements and names the width every measurement came from. No sidebar, no tab bar, and no account surface on either client, because the edge authenticates the browser before the app exists. The argument is in ticket 13, and each screen's record and specimen land here as it is drawn.

The palette at a glance

Instrument black, one green telltale, and a fault vocabulary that never uses the accent. docs/DESIGN.md is the narrative record; README.md explains which one is authoritative.
