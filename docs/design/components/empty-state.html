PlayLiberty design / empty state
Components

Empty state

A playlist that exists, is named, and has no tracks, because lastSyncedAt is still null. One action and three facts, and the whole component is those four things on one axis.

The state, and the action working

Same words in both. Everything the state says is still true while the action runs.

Nothing here yet

This playlist has never been synced, so there is nothing to play. Syncing goes to YouTube and downloads the audio of every track in the playlist.

A sync takes a few minutes. Once a track is downloaded it is yours: if the video is later removed from YouTube, the track still plays here.

What is not drawn

The first sync failing. That is PlaylistSyncStatus.Error with a null lastSyncedAt, so it is reachable from here, and it is a fault rather than an absence. This surface says nothing is wrong, and a failed first sync has to say something is, so the words here must not survive into it. It belongs to the sync error.

The library with no playlists at all. A different component with a different action, Add a playlist, and this is not it.

Whether the surface is --surface or --bg. The list this replaces is --surface and the page behind it is --bg, and picking between them is a screen decision. Every pairing here holds either way: --ink on --surface is 14.73:1 and --muted on --surface is 5.71:1.

Usage

Do keep it to one control. There is no second thing to do here, and a second button on an empty state is a feature the product has not decided to have. Do keep the three facts on three lines, so none of them can be read as part of another, and do not change the words when the action runs, because they are all still true. Do not repeat the playlist's name or draw its cover: the header owns the playlist's identity and this owns the fact that the playlist is empty, and a name repeated forty pixels below itself is duplication rather than reassurance. Do not put a second line under the title unless it has something to say, since TrackSchema has no artist and no album and the resting file state has no word.
