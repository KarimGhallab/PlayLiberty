The whole row is deliberately not clickable. A row carries a title, a source, a state, a duration and a menu, and making the row a target means every one of those competes with it for the same tap. Only the controls are targets.

At 390px the duration and the action hold their lanes and the title truncates, because those three are structural. The failure reason wraps onto a second line instead, because it is the only part of the row the user cannot reconstruct elsewhere.

Motion

The in-flight breath runs on --motion-slow and is the only animation in the component. It dims the row's artwork, title, duration and menu together and restores them, so nothing travels and the text is never redrawn, which is the property the rest of this row is built around. It is deliberately shallow, to --opacity-disabled, because it moves three lanes at once and a deeper dip would cost the user the row rather than announce it.

Not a progress bar: the API carries no percentage, and a bar that implies a number the product does not have is worse than movement with no number at all. Not a highlight across the title either, which was the alternative, because a gradient behind 14px text animates a glyph run on the one element that has to stay quiet.

Under prefers-reduced-motion: reduce the breath stops and the word "Downloading" carries the state on its own. That is why the word is always present rather than being implied by the motion.

Usage

Do keep the lanes fixed, so the duration column stays a column. Do show the reason when there is one, since the user cannot reconstruct it. Do keep "Removed" dimmed rather than struck, because a strikethrough reads as deleted and the track is still playable. Do offer retry only where retrying can work, which is why a failed row has it and an unavailable one does not. Do not label the default state, since a row with nothing wrong should not announce it. Do not make the whole row a target.
