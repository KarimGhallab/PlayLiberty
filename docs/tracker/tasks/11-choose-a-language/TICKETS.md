## Conventions

- One file per ticket, numbered from `01` in dependency order, blockers first.
- A ticket with no blockers can start immediately; the frontier is every ticket whose blockers are done.
- Each ticket is a tracer bullet: a complete path through the package, the client and the tests, demoable on its
  own. Ticket 01 is the largest because it lands the package and the pattern every later ticket extends.
- Tests run in `en`; the typed catalog is what proves every French key exists, so no test walks the French
  catalog.
- Resolve a ticket by recording its outcome in the ticket and updating its row here. Do not delete it.
