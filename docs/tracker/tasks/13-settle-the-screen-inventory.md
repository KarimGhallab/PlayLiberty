# Settle the screen inventory

Status: resolved
Labels: `enhancement`, `ready-for-agent`

## Outcome

The inventory is four screens, two per client: the library and the playlist detail. A screen is a surface a user reaches by route, so it is one design task with two arrangements. The library is one list with no sections, and there is no fixed sidebar and no mobile tab bar. A `write` share permits add, remove and sync; rename, delete and share management stay with the owner. The jobs are the capabilities in [`PRODUCT.md`](../../PRODUCT.md), and the permission rule is in specs [`04`](../specs/04-curate-a-playlist.md) and [`05`](../specs/05-share-a-playlist.md).
