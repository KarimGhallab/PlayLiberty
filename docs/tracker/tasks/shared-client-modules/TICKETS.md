# Cross-client shared modules

Tickets for the architecture review of 3 November 2026. One file per ticket, numbered in dependency order. The set moves the modules that `apps/web` and `apps/mobile` each own into two new packages and three existing ones.

The packages: `@playliberty/client-data` (new) holds the API protocol and every read and command. `@playliberty/player` (new) holds the pure queue rules. `@playliberty/query`, `@playliberty/ui-foundation` and `@playliberty/i18n` gain the cache patch, the permission and action lists, the state vocabulary and the sentences.

## Conventions

- One file per ticket, numbered from `01` in dependency order, blockers first.
- A ticket with no blockers can start immediately. Ticket `01` is the only one.
- Tickets `05` to `08` can run in parallel with `02` and `03`, because they touch different modules.
- A ticket is done when its acceptance criteria hold and its verification passes. Record the outcome in the ticket, then update its row here. Do not delete it.
- The report behind this set lives outside the repository. Its line numbers are evidence for the first draft, not a specification.
