# 21: Harden the library's edges

**Status:** resolved

## Outcome

A long name is recoverable by pointer: the name element carries `title={playlist.name}` on the detail's heading and the library's link alike, the same reveal `TrackRow` already uses for its ellipsized failure reason. `useDeferredAction` reports `replaced`, the action the current window displaced, and `windowId`, the window's ordinal, so `LibraryPage` words the dropped intent and `UndoToast` draws it under the current one, with the `status` region announcing `“Rain On The Window” will not be deleted` when a second delete replaces the first; a repeated press of the same item is the same intent and reports nothing. The countdown ring is keyed to the window, so a replacement restarts its sweep instead of leaving the old window's progress on a fresh one.

See [`08-see-the-library`](../specs/08-see-the-library.md).
