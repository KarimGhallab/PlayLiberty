## Conventions

- One file per ticket, numbered from `01` in dependency order, blockers first.
- A ticket with no blockers can start immediately; the frontier is every ticket whose blockers are done.
- Each ticket is a tracer bullet: a complete path through the screen and the reads it makes, demoable on its own.
- Ticket `01` is a prefactor: the account sheet's frame moves into one shared component before the add and actions sheets reuse it.
- The card's play control is drawn disabled in `02`; the player is spec `23`'s and enables it.
- The actions sheet in `07` draws the full access-filtered item set. Share, Rename and Cover open placeholder sheets; specs `26`, `25` and `29` replace their bodies.
- The egress door stays in the library header, per spec `19` and `DESIGN.md`; spec `21`'s sentence that places it in the account sheet is stale.
- The first gallery read requests the route's maximum page, so the scope and chip counts are whole up to that size; later pages append beyond it.
- Resolve a ticket by recording its outcome in the ticket and updating its row here. Do not delete it.
